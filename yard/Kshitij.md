# 🌱 Small Yard Gardening Toolkit (Learning Enthusiast Edition)

**Yard size:** ~2,000 sq ft  
**Features:** Grass, hedge, a few trees  
**Goal:** Build skill, understanding, and a scalable tool system

---

# 🧠 Philosophy

This setup is designed to help you:
- Learn **soil, plant growth, and lawn care fundamentals**
- Build **hands-on intuition** (not just push-button results)
- Create a **modular tool ecosystem**
- Iterate and expand over time

---

# 🧰 Core Toolkit (Start Here)

## 1. Hand Tools (Soil & Plant Learning)

**Recommended:** Garden Guru 6-Piece Tool Kit

**Purpose:**
- Digging, planting, transplanting
- Weeding and soil exploration

**What you learn:**
- Soil structure (clay vs loam vs sand)
- Root systems and moisture behavior

**Why it matters:**
This is your *foundation layer*—you’ll use these constantly.

---

## 2. Lawn Mower (System Anchor)

**Recommended:** EGO Power+ 21" Cordless Push Lawn Mower

**Purpose:**
- Grass cutting (weekly)

**What you learn:**
- Cutting height effects
- Mulching vs bagging
- Lawn health cycles

**Why this choice:**
- Powerful enough to experiment
- Battery ecosystem expands to other tools

---

## 3. String Trimmer (Precision Control)

**Recommended:** DEWALT 20V MAX String Trimmer

**Purpose:**
- Trim edges
- Clean around trees and obstacles

**What you learn:**
- Edge definition
- Grass spread patterns
- Fine motor control in landscaping

---

## 4. Hedge Trimmer (Plant Shaping)

**Recommended:** BLACK+DECKER 20V MAX 22" Hedge Trimmer

**Purpose:**
- Shape hedges
- Control growth

**What you learn:**
- Pruning timing
- Growth response to cuts
- Geometry (flat vs tapered hedges)

---

## 5. Lawn Rake (Cleanup & Observation)

**Recommended:** Ames Multi-Purpose Lawn Rake

**Purpose:**
- Leaves, clippings, debris

**What you learn:**
- Lawn density
- Seasonal debris patterns

---

# 🧭 How to Use This Setup (Learning Approach)

## 1. Run Experiments
- Mow at different heights → observe color and growth
- Trim hedge unevenly → compare regrowth
- Water different zones → compare soil retention

---

## 2. Build Systems
- Establish a mowing pattern
- Maintain consistent edges
- Schedule seasonal trimming

---

## 3. Iterate Tools
- Start with core tools
- Add tools when you feel limitations
- Upgrade intentionally (not impulsively)
