# Kitchen reno — 2024

## Design goals
- Eat-in kitchen for family meals (very important)
- Improve perceived value of home (don't decrease it)
- Design for finesse, foresee small issues

## Design ideas
**Banquette:** 15" seats with 18" stone top (or 24" seats). Pony wall from living room or kitchen floor.
**Counter seating:** step-down, chairs at different heights same style.

## Cabinet sizing (from Krystal)
- 15" high cabinets — available, no corners
- 20" high: angled corner cabinet 26×20"
- Seating depth: 15" cabinets in 24/30/36" widths; 24" deep in 30/36"
- 18" depth requires 2×4 support from contractor
- With 24" depth: extends kitchen ~6" → hits window; 36" seat next to window + 27" corner filler = 63"
- Normal seating height: 18–20". Recommendation: use 15" tall cabinets.

## Renovation sequence
1. Engage designer + prepare plans
2. Document 2 viable designs (with labels for where things go)
3. Get 2 quotes — Eric + Vini
4. Apply for permit
5. Put old appliances for sale (blinds, doors, oven, cooking range — get model #s; dryer available free)
6. Eric does demo + kitchen + garage cabinets + washing machine area
7. Precise measurements for cabinets
8. Order cabinets + appliances
9. Install cabinets
10. Measure for countertop + backsplash → order
11. Install countertop + backsplash
12. Install appliances

## Renovation phases (structural)
Demo → Rebar → Inspection → Concrete → Epoxy → Earthquake retrofit → Outside drainage

## Inspector checklist
