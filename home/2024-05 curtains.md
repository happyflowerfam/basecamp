# Curtains

## Sizing
- Track width: 1.3× window width, OR 6–10" extra each side
- Length styles: Float (< 1" above floor) · Kiss (1mm above) · Puddle (2–4" excess — high quality only)
- Curtain width: 1.5–2.5× window width

## Fabric
- Synthetic blend — best for durability
- Silk disintegrates; linen wrinkles

## Style
- S-fold on a track — easy to open/close, clean look

## IKEA options (57" wide)
Ritva · Sanela · ANNAKAJSA · Vilborg · Tibast · Moalina · Ringblomma (Roman shade) · Dytag

## Color direction
No blue. No white.

## To measure + order
- Calculate curtain dimensions + track lengths for all windows
- Write out full specs before ordering
- Blinds: Chicology blackout blinds (order after precise measurements)
