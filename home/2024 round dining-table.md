# Dining table sizing

Room: 11ft × 9.5ft (132" × 114")
Table footprint target: 92" × 40"
Clearances: 10" near the step, 30" other side, 38" on either side

**Final choice:** Daals Maru round 4–6 seater extending oak pedestal dining table

## Options considered
- **Skogsta** chairs + table: $390 + $550 = **$940**
- **Karsten** chairs + table: $229 × 6 + $900 = **$2,274**

## Chair/table height reference
- Standard table: 28"–30" | standard seat: 18"–23"
- Counter height table: 34"–36" | counter seat: 24"–27"
- Bar height table: 40"–42" | bar seat: 28"–33"
- Height differential between table and seat: ~12"

## Kitchen measurements (Apr 2024)
- Window to edge: 22.4"
- Table calculation: 22" + 10" = 30" (table height)
- Total span: 51.5"
